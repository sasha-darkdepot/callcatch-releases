# CallCatch releases

Signed and notarized builds of **CallCatch**, a macOS menu-bar utility that notices calls in Discord, Signal, Telegram and WhatsApp and starts and stops a recording in the Plaud desktop app.

This repository holds release files only. The source code is private, and the source archives GitHub attaches to each tag contain only this README and the license.

## Install

1. Open the [latest release](https://github.com/sasha-darkdepot/callcatch-releases/releases/latest) and download `CallCatch-X.Y.Z.dmg`.
2. Open the dmg and drag **Call Catch** to Applications.
3. Open it. macOS asks for Accessibility access once; CallCatch needs it to stop Plaud recordings.

Requires macOS 26 or later on Apple Silicon.

## Updates

CallCatch checks this repository once a day and offers new versions with one click. It never restarts during a call or a recording. You can also choose **Check for Updates…** in its menu. Builds older than 0.5.0 do not update automatically; install 0.5.0 from the dmg once.
